# Teluk Senja Labuan Bajo

Concept website for a fictional oceanfront hotel in Labuan Bajo, Flores. Bilingual (English / Bahasa Indonesia), mobile-first, built with Vite, React, TypeScript and Tailwind CSS.

Photos are illustrative, from Wikimedia Commons under free licences; credits are listed in the site footer.

```bash
npm install
BASE_PATH=/Teluk-Senja-Hotel-Website/ PRELOAD_FONTS=bodoni-moda-latin-wght-normal,bodoni-moda-latin-wght-italic,outfit-latin npm run build
```
